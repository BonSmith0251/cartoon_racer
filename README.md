# Cartoon Racer reconstruction

Editable reconstructed Unity project targeting **Unity 2023.2.22f1**. Open the repository root in Unity, then open `Assets/MENU.unity`.

All project files, including the large School scene, are stored directly in Git. Git LFS is not required.

See [RECONSTRUCTION.md](RECONSTRUCTION.md) for recovery coverage and limitations and [the terrain audit](Recovery/terrain-check/REPORT.md) for the confirmed missing farm paint maps and pending School shininess check. These terrain findings have not been repaired.

Generated builds, Unity caches, original game binaries, duplicate extraction payloads, personal save backups and bulk object dumps remain local and are not committed. Some recovery scripts and reports refer to those local evidence files and machine-specific tool paths. The editable project is contained in Assets, Packages and ProjectSettings.
